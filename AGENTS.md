# The Uke Project: agent notes

A four-page static marketing site for a ukulele teacher serving retirement homes and senior communities. Built on TanStack Start (React 19, Vite, Tailwind v4) and deployed on Netlify.

## Key files

- `src/content/site.ts`: **all copy and contact details**, plus the `nav` list and the `img()` helper that builds Netlify Image CDN URLs. Change wording here, not in the route components.
- `src/routes/`: `index.tsx` (Home, which also holds the contact form at `#contact`), `program.tsx` (includes the FAQ accordion), `research.tsx`, `about.tsx`. There is no separate Contact or FAQ page; `netlify.toml` redirects the old `/contact` and `/faq` URLs. `__root.tsx` holds the site-wide meta tags, Google Fonts link, skip link, header/footer, and the 404 page.
- `src/components/Layout.tsx`: `SiteHeader` (dark bar so the pale logo yellow stays legible; desktop nav plus mobile menu), `SiteFooter`, `PageHeading`, `CtaBand`, and the `Logo` component.
- `src/components/InquiryForm.tsx`: the contact form, with AJAX submission and pending, success, and error states.
- `public/inquiry-form.html`: the hidden static copy of the form that Netlify scans at deploy time. **Its field names must match `InquiryForm.tsx` exactly**; update both together. The form POSTs to `/inquiry-form.html`, not `/`, because the SSR catch-all would intercept `/`.
- `public/img/`: the owner's stock photos (`class-smiling` Home hero, `lounge-duo` and `duet-music-stand` Home, `instructor-playing` Program, `park-group` Research), the headshot `james-walsh.jpg` (About), and both logo versions (`logo-text.png` in the header, `logo-wrap.png` in the footer, rendered via `<Logo variant>` in `Layout.tsx`). Always reference them through `img(file, width)` rather than linking the large PNGs directly.
- `src/styles.css`: theme tokens taken from the logo (`cream`, `paper`, `ink`, `teal`, `mint` = logo green, `sun` = logo yellow; `mint` and `sun` are too light for text on light backgrounds, so use `teal` there), the button classes, and the `.scribble` highlight and `.rise` entrance animation.

## Conventions and decisions

- The audience is older adults and activity directors, so keep the base font large (19–20px root), contrast high, touch targets at least 48px, and motion minimal (everything respects `prefers-reduced-motion`). The body font is Atkinson Hyperlegible, chosen for legibility; Caladea (an open-source Cambria match, since the logo uses Cambria) is the display font.
- No database or server logic is needed. The only dynamic feature is Netlify Forms.
- The copy in `site.ts` is the owner's own wording from their Squarespace site; keep it verbatim apart from typo fixes. Still placeholders: the email, phone, and the heading/intro above the contact form.
- `src/routeTree.gen.ts` is generated by the build; don't edit it by hand.
